# Our *Valheim* Dedicated Server

## Install Steps
1. On this *GitHub* page, click the green `Code` button and then `Download ZIP`.
2. Extract the ZIP file and copy all the folders and files .
3. Paste them into the main *Valheim* folder (`Steam\steamapps\common\Valheim`).

### Result
The contents of the ZIP file are in the same folder as `Valheim.exe`.

If everything is okay, the `BepInEx` console window will start when *Valheim* starts.

## Join Server Steps
1. Install *ZeroTier* and join the network. Ask someone for the full Network ID.
2. Check that the network ID starts with `83...` and is `pedantic_...` for our server.
3. Start *Valheim*, select character and go to `Join Game`.
4. Click `Add Server` and enter: `192.168.191.26`

### Result

The server is displayed here after adding it (port is automatically added).
