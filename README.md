# Valheim Mods

## Install Steps
1. On this page, click the green `Code` button and then `Download ZIP`.
2. Extract the ZIP file and copy the `BepInEx` folder.
3. Paste the folder to the main Valheim folder `Steam\steamapps\common\Valheim`.
